离线朗读引擎 · 第三方组件与许可声明
=====================================

本目录包含小火「语言学习」内置离线朗读引擎，用于在本机 Windows 未安装对应
语种系统语音包时，按目标语种正确发音（例如把 "300" 读成 three hundred、
日语按日语音读，而不是交给中文嗓音念）。

组件
----
1. eSpeak NG 1.52.0（文本转语音引擎，编译为 WebAssembly）
   许可：GPL-3.0-or-later
   上游：https://github.com/espeak-ng/espeak-ng
   本目录 data/ 下的词典数据（*_dict.gz）、core.bin.gz、manifest.json
   均派生自 eSpeak NG 的 espeak-ng-data。

2. @spelling-creator/spellophone 0.2.1
   （eSpeak NG 的 WebAssembly / JavaScript 封装，提供 createEspeak、
   synthesize、encodeWav 等接口）
   许可：GPL-3.0-or-later
   上游：https://github.com/Spelling-Creator/spellophone
   获取：https://registry.npmjs.org/@spelling-creator/spellophone/-/spellophone-0.2.1.tgz
   本目录 spellophone.iife.js、espeak-ng.wasm 来自该 npm 包，未作修改。

使用范围
--------
仅用于语言学习的朗读兜底。完全离线运行：不联网、不上传任何文本、不需要
API Key、不依赖 Windows 系统语音包。系统装了对应语种嗓音时，程序会优先
使用系统嗓音（音质更自然），本引擎仅作兜底。

已知限制
--------
eSpeak NG 是规则式合成，音质为机械音；日语汉字无读音数据（假名可正常朗读），
复杂的汉字词可能读成 "Chinese letter"。想要自然读音请安装 Windows 对应
语音包（设置 → 时间和语言 → 语音）。
