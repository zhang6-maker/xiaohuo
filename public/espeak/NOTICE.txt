内置朗读引擎 · 第三方组件与许可声明
=====================================

小火「语言学习」的朗读功能随程序内置了两套离线语音引擎，均在本机运行：
不联网、不上传朗读文本、不需要 API Key、不依赖 Windows 已安装的语音包。
本文件列出各组件的来源与许可，供再分发时遵守。

使用范围与已知限制
------------------
- 英语：默认走 A 组神经模型，音质接近真人；首次朗读需加载模型约 3–10 秒，
  之后约 1 秒出声。加载失败会自动回退到系统嗓音 / B 组引擎。
- 日语、韩语、法/德/西等：走系统嗓音（若本机装了对应语音包），否则由
  B 组 eSpeak NG 按目标语种合成——是规则式机械音，且日语汉字无读音数据
  （假名可正常朗读，复杂汉字词可能读成 "Chinese letter"）。
- Piper 的日语模型采用 OpenJTalk 音素集，当前运行时只带 eSpeak 音素化器，
  无法直接使用，故日语未提供神经语音（已实测会卡死）。
- 用户在「朗读嗓音」下拉中可随时手动切换到「内置离线引擎」强制完全离线。

技术说明
--------
所有资源位于程序内嵌的 public/piper/ 与 public/espeak/，由 Tauri 打包进
可执行文件，运行时通过 document.baseURI 解析为绝对 URL 动态加载，
不向任何外部服务器发起请求。
